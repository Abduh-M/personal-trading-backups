# Personal Trading Backups

Personal Trading Backups is a private-use automation tool maintained by
Abduh-M. It uses rclone and the Google Drive API to back up the owner's
trading research files, session recordings, logs and reports to the
owner's Google Drive.

The tool is for the owner's personal use and is not a public service.
Google Drive access requires the owner's authorization.

This website contains information about the tool only. It does not
provide access to backups, trading accounts or Google credentials.
