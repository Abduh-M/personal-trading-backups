# Privacy Policy — Personal Trading Backups

Last updated: October 20, 2026

## Purpose

Personal Trading Backups is a personal-use tool maintained by Abduh-M.
It uses rclone to transfer and verify the owner's research files,
session recordings, logs and reports in the owner's Google Drive.

## Google Drive access

The tool uses the Google Drive permissions granted by the owner.
These permissions may allow access beyond the designated backup folder.
Its configured backup tasks use designated folders to upload files,
list file metadata and verify backup integrity.

## Storage and security

Backup files are stored on the owner's devices or server and in Google
Drive. OAuth credentials are stored in private rclone configuration
files on the owner's devices or server. Credentials and backup contents
are not published on this website or in its GitHub repository.

## Sharing and use

Google user data accessed by this tool is used only for the personal
backup workflow. It is not sold, used for advertising or used to train
general-purpose AI models. Files are processed by the storage and
hosting providers involved in the backup workflow.

## Retention and control

The owner controls retention and deletion of local and Drive backups.
Removing a local copy does not automatically remove the Drive backup.
Revoking authorization stops future access but does not delete
previously uploaded files.

Access can be revoked through the Google Account's third-party
connections settings.

## Website

This informational website is hosted by GitHub Pages. It contains no
Google sign-in form or custom analytics. GitHub may process technical
visitor information under its own privacy statement.
